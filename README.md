# CloudAMQP examples

Minimal examples of connecting to [CloudAMQP](https://www.cloudamqp.com), or any
AMQP 0-9-1 broker such as [LavinMQ](https://lavinmq.com) or RabbitMQ. Examples are
grouped by language and then by client library. Each library folder is a
self-contained project with its own README.

| Example | Description |
|---|---|
| [clojure/langohr](clojure/langohr) | Clojure publish/consume with [Langohr](https://github.com/michaelklishin/langohr) |
| [crystal/amqp-client](crystal/amqp-client) | Crystal publish/consume with [amqp-client.cr](https://github.com/cloudamqp/amqp-client.cr) |
| [dotnet/rabbitmq-dotnet-client](dotnet/rabbitmq-dotnet-client) | .NET publish/consume with the [RabbitMQ .NET client](https://github.com/rabbitmq/rabbitmq-dotnet-client) 7 |
| [go/amqp-client](go/amqp-client) | Go publish/consume with [amqp-client.go](https://github.com/cloudamqp/amqp-client.go) |
| [java/rabbitmq-java-client](java/rabbitmq-java-client) | Java publish/consume with the [RabbitMQ Java client](https://github.com/rabbitmq/rabbitmq-java-client) |
| [nodejs/amqp-client](nodejs/amqp-client) | TypeScript publish/consume with [amqp-client.js](https://github.com/cloudamqp/amqp-client.js) |
| [php/php-amqplib](php/php-amqplib) | PHP publish/consume with [php-amqplib](https://github.com/php-amqplib/php-amqplib) |
| [python/celery](python/celery) | Python [Celery](https://docs.celeryq.dev) app using CloudAMQP as the broker |
| [python/pika](python/pika) | Python publish/consume with [Pika](https://github.com/pika/pika) |
| [ruby/amqp-client](ruby/amqp-client) | Ruby publish/consume with [amqp-client.rb](https://github.com/cloudamqp/amqp-client.rb) |
| [ruby/mqtt](ruby/mqtt) | Ruby MQTT publish/subscribe with [ruby-mqtt](https://github.com/njh/ruby-mqtt) |
| [rust/amqp-client](rust/amqp-client) | Rust publish/consume with [amqp-client.rs](https://github.com/cloudamqp/amqp-client.rs) |
